Easy English with Anastasia

Website Planning Document

Site Name

Easy English with Anastasia

This name was chosen because it creates a friendly and personal learning environment. The website is designed to help English learners improve their skills with simple lessons and practical activities.

Optional Domain: easyenglishwithanastasia.com

Site Purpose

Easy English with Anastasia is an educational website that helps English learners improve their vocabulary, grammar, pronunciation, and everyday communication skills. The website will provide lessons, study tips, useful phrases, and interactive practice activities.

Scenarios

  • How can I improve my English vocabulary every day?
  • Where can I find easy grammar explanations and practice activities?
  • What English phrases should I learn for daily conversations?
  • How can I practice English speaking on my own?

Color Schema

#2563EB (Blue) - Used for headings, buttons, and navigation.

#10B981 (Green) - Used for accents, highlights, and links.

#F8FAFC (Light Gray) - Used for page background.

Typography

Poppins will be used for headings, navigation, and titles.

Open Sans will be used for body text, paragraphs, and lesson content.
